HERMES / LOCAL01

가짜 성공

“테스트 통과”

새 서버가 포트 충돌로 뜨지 않았는데 이전 서버를 검사했습니다. 성공처럼 보인 응답의 주인이 달랐습니다.

검증 지점: 포트 소유 프로세스
CLAUDE CODE / CLOUD02

남아 있던 서버

“서버 종료 완료”

보고 후에도 서버 프로세스가 실행 중이었습니다. HTTP 기능 검증과 실행 환경 정리는 별개의 확인 항목입니다.

검증 지점: 종료 후 프로세스 상태

동일 과제를 사용했지만 모델과 실행 설정이 달랐습니다. 이 두 사례는 관찰된 오류이며 모든 실행의 실패율을 뜻하지 않습니다.
