# 차민수 · AI 업무 시스템 설계

GitHub Pages 포트폴리오의 첫 초안입니다. `index.html`은 소개와 대표 프로젝트, `demo.html`은 공개용 가상 요청을 단계별로 보는 사례 화면입니다.

현재 데모는 미리 작성한 예시 내용을 보여줍니다. AI 모델을 호출하거나 실제 회사 업무를 처리하지 않습니다. 효과 수치도 아직 측정하지 않았습니다.

## 로컬에서 보기

`index.html`을 브라우저로 열거나 이 폴더에서 `python3 -m http.server 8000`을 실행한 뒤 `http://localhost:8000/`으로 접속합니다.

## 첫 프로젝트의 다음 단계

1. 공개 가능한 가상 요청 10~20건과 검토 기준을 작성합니다.
2. 모델을 연결해 요구사항, 질문, 위험 항목을 구조화합니다.
3. 입력 근거와 모델 추론을 구분하고, 근거가 없는 주장에 표시를 붙입니다.
4. 사람이 수정·승인·보류한 이유를 저장합니다.
5. 누락률과 수정 시간을 기존 수작업 방식과 같은 기준으로 비교합니다.

개인정보와 회사 자료가 들어간 입력은 공개 저장소에 올리지 않습니다. 변경은 작업 브랜치에서 Pull Request로 `main`에 합칩니다.
