# 차민수 · AI 실험과 검증

GitHub Pages 포트폴리오 초안입니다. 첫 화면은 차민수의 PM 경력·담당 업무·개인 AI 실험을 소개합니다. 대표 사례로 에이전트의 성공 보고를 독립 검사한 실험을 시각화합니다. `demo.html`에서 세 실행 환경의 관찰 결과를 비교할 수 있습니다.

## 만든 서비스

`mailbox.html` — **우리 가족 우체통**. 떨어져 지내는 가족이 편지와 일정을 나누는 모바일 웹입니다(대학 「AWS클라우드실습프로젝트」 개인 프로젝트). S3·CloudFront·Cognito·API Gateway·Lambda·DynamoDB·CloudWatch로 구성해 2026-11-23 서울 리전에 배포했고, 가족 계정으로 편지 전달과 읽음 기록을 확인했습니다. 가족 전용 서비스라 공개 주소와 소스 저장소는 싣지 않았고, 페이지의 화면 사진은 로컬 예시 데이터로 찍었습니다.

## 관찰한 사실

2026년 개인 실험에서 동일한 TODO 웹앱 과제를 세 실행 환경에 맡겼습니다. Hermes는 새 서버가 시작하지 못했는데 이전 서버의 응답을 검증해 성공을 보고했고, Claude Code는 종료했다고 보고한 서버 프로세스가 남아 있었습니다. OpenClaw는 기본 승인 정책에서 무인 실행이 중단됐습니다.

과제는 한 종류이고 모델과 설정도 달랐습니다. 이 결과를 전체 제품의 성능 순위나 일반적인 실패율로 해석하지 않습니다.

## 만들 프로젝트

**Agent Proof Lab**: 에이전트가 만든 결과물을 별도 실행 공간에서 검증하고, 보고한 주장과 파일·HTTP 응답·프로세스 상태의 증거를 연결하는 공개용 도구입니다. 현재 저장소에는 실험 결과를 설명하는 사이트 시안이 있습니다. 검증 도구 자체와 반복 실행 결과는 아직 구현·공개하지 않았습니다.

첫 구현 기준은 다음과 같습니다.

1. 동일 과제를 여러 실행 환경에 제공한다.
2. 각 실행에 별도 작업 폴더와 포트를 할당한다.
3. 결과 파일, HTTP 기능, HTML 이스케이프, 서버 종료 여부를 에이전트 밖에서 확인한다.
4. 에이전트 보고와 외부 검증 결과를 구조화된 기록으로 남긴다.
5. 공개 가능한 사례 여러 건에서 잘못된 성공 판정과 재현성을 측정한다.

원본 실험 기록은 별도 개인 프로젝트에 있습니다. 공개 전 자료 범위와 라이선스를 확인합니다. 회사 정보와 고객 정보는 사이트에 넣지 않습니다.
